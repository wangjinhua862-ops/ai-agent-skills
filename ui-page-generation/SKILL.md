# AI Agent 控制台原型（Figma 插件流水线）

用户会给出：ASCII 线框图 + 文字设计规范（字号/颜色/间距/组件）。你要产出的不是图片，而是**在 Figma 里点一下按钮就能生成的、可继续编辑的原生图层**。

## 工作流

0. **读需求**：用户给新页面时按 `references/request-template.md` 理解（页面编号 + 页面名 + 结构 + 是否要中英双版，一句话就能开工）；用户没说的项走默认值，不要反问。
1. **定位工程**：默认插件工程
   - 项目镜像（在此编辑）：`<你的项目根>/交付/Figma插件/ai-agent-prototype-kit`
   - 安装目录（Figma 实际加载）：`<你的 Figma 插件目录>/ai-agent-prototype-kit`
2. **判断是新页面还是改现有页面**。改现有页面 → 直接改对应 `src/pages/*.js`；新页面 → 跑脚手架：
   ```bash
   node <skill>/scripts/scaffold_page.mjs --src <项目镜像> --id <page-id> --title "<帧名>" --button "<按钮文案>" --prefix "<清理前缀>"
   ```
3. **按规范写页面**：严格套用 `references/design-system.md`（v3.1 定稿：外壳尺寸、颜色、卡片配方、字阶、彩色文字用法）；风格基线就是 `src/pages/agent-config-v3.js`（02-01 重构），新页面从它复制常量和助手，不要自创一套。布局按 ASCII，不自由发挥结构。
   **三块固定外壳必须逐像素照抄**（导航条、顶栏右端四图标、问候卡「早上好，{用户名}」+ 日期）—— 用户 2026-09-18 明确要求这三块每页不变；新页面只允许改「顶栏页面名 + 主区内容 + 问候卡副标题那一句」。
4. **构建**：在项目镜像里 `node build.mjs`，再用 `node --check code.js` 验证语法。
5. **同步安装目录**：把 `code.js` / `ui.html` / `src/` 复制到安装目录（写 E 盘需要用户授权，用一次 PowerShell `Copy-Item`）。
6. **交付话术**：告诉用户「关掉插件面板 → 重新打开（改代码必须重开）→ 点第 N 个按钮」，并附验收清单。

## 中英双版规则

- 所有文案集中在页面文件顶部的 `V3_LANG.cn` / `V3_LANG.en` 两张表里，**布局与样式只有一套**；改文案只改语言表，两版同时生效。
- 中文版：帧名前缀 `02-01 重构｜`，由按钮 ① 生成；英文版：帧名前缀 `02-01 EN｜`，由按钮 ② 生成。
- 英文版生成时**必须**自动贴到中文版正下方（同一 x，间隔 80），并把两帧一起 `scrollAndZoomIntoView`，保证用户在一个视口里同时看到中英对照 —— 这是用户提过的体验问题，别再退回"只定位一帧"。
- 中文版重生成时，如果英文版已存在，也要把它重新对齐到中文版下方（`alignEnglishUnder`）。
- 页面上只保留这两个版本；历史上的 v1（`02-01｜`）与定稿版（`02-01 定稿`）**已删除**，按钮 ④「清理旧版本帧」负责清掉画布上残留的旧帧。

## 帧命名与清理前缀

| 版本 | 帧名 | 清理前缀 |
|---|---|---|
| 中文重构版（当前） | `02-01 重构｜…` | `02-01 重构｜` |
| 英文版 | `02-01 EN｜…` | `02-01 EN｜` |
| 早期定稿版 | `02-01 定稿…` | `02-01 定稿` |
| 最早一版 | `02-01｜…` | `02-01｜` |

清理前缀必须**只删自己那一版**；用 `"02-01"` 会把中英和旧版一起删掉。

## 不可违反的约束

- **不删已有页面**：新页面用自己的帧名与清理前缀（`removeGenerated("<前缀>")`），绝不调用会匹配到旧页面的前缀。
- **帧位置**：新帧用 `nextFreeX()` 放到已有内容右侧，避免重叠、避免残影。
- **不编造业务信息**：ASCII/规范里没有的字段、指标、技术名词一律不加（如响应时间、权限等级、OAuth、沙箱）。
- **纯中文**：除非规范明确要求，否则页面不出现英文。
- **风格克制**：不要渐变、发光、粒子、玻璃拟态、大徽章、大 Logo；AI 感来自"Agent → 系统能力 → 连接状态"，不是特效。

## 技术红线（不遵守会直接报错或生成空白）

- 所有文本必须经 `makeText` / 页面的 `v3Txt` 等 **await** 助手创建（内部先 `loadFontAsync`）；直接 `figma.createText()` 后设未加载的字体必崩。
- `layoutGrow` / `layoutAlign` **只能**用于 auto-layout 的子节点，且必须先 `appendChild` 再设。
- 非 auto-layout 的父级上不要设上述两个属性；根帧内的大区用绝对定位。
- 细节见 `references/figma-api-pitfalls.md`。
