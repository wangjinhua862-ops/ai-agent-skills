# 品牌基因 · 通用骨架（Brand DNA Skeleton）

> **这个文件是占位骨架，不是最终规范。**
> 改站前先读**项目自己的**品牌基因文件（默认 `docs/品牌基因.md`，路径可与用户确认）。
> **冲突时一律以项目文件为准**——它才是这个站唯一的视觉与语气依据。
> 组织方式参考 **ESTHER不二 / esther-design-system**（CC BY-NC-SA 4.0）。
> 找不到项目品牌文件时，先用下面这套通用默认值起步，并把最终定稿写回你的项目文件。

## 1. 先定义三件事

开工前把这三条写下来（不知道就问用户，**不要自己猜**）：

1. **定位**：这个站为「谁」说「一句什么话」？（一句话，不是形容词串）
2. **视觉主张**：一句话说清它「看起来像什么」（例：浅底 + 深墨衬线巨字 + 极少量强调色，其余留白）
3. **气质关键词**：3 个，每个都写清「是 / 不是」

| 气质关键词 | 是 | 不是 |
| --- | --- | --- |
| ① | | |
| ② | | |
| ③ | | |

**一句话自检**：页面缩到 30% 看不清字时，它还像**一份认真做的产品文档**吗？像「又一个 AI 落地页」就不对。

## 2. 母题（可选；一旦定了就极克制）

站如果有视觉母题（某种图形 / 材质 / 自然物），它比配色更值钱。三种强度，**一页只用一层**：

| 强度 | 用法 | 出现位置 |
| --- | --- | --- |
| 弱 | 1px 线稿 / 分隔线端点的小形 | 分隔带、Footer |
| 中 | 母题轮廓当构图参考（图偏一侧、留白不对等） | 章节标题区 |
| 强 | 实拍做纸感背景带 | 联系区 / 横幅 |

**禁止**：母题当图标到处撒；描边 + 渐变；3D / 玻璃材质；出现第二套母题。

## 3. 色板（填你自己的值）

先定 token 名，再填值。**每个 token 只干一件事**：

| token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | | 主背景（浅色） |
| `--surface` | | 次级纸面 / 卡片 |
| `--line` | | 边框、分隔线 |
| `--ink` | | 主文字 |
| `--ink-l` | | 次要文字（对比度 ≥ 4.5:1） |
| `--ink-f` | | **只能做分隔线 / 占位**，不承载要读的信息 |
| `--brand` | | 结构与交互主色 |
| `--brand-l` | | 次强调 |
| `--brand-p` | | 浅色底 |
| `--accent` | | 极少量强调 |
| `--accent-l` | | 强调色浅底 |

**用色纪律**

- 主背景占绝对多数，结构色少量，强调色**极少量**（一屏最多出现一次）。
- `--accent` **永不做文字色**；`--ink-f` **永不承载要读的信息**。
- **深色面板全站只用一块**（用来打破节奏），出现第二块说明节奏乱了。
- 链接默认 `--brand` + 下划线；hover 只加深，不做「变色 + 位移 + 发光」三连。

## 4. 字体（按角色选，不按喜好选）

| 角色 | 字体 | 要求 |
| --- | --- | --- |
| 英文标题 | | 衬线优先，纸感来源 |
| 英文正文 / UI | | 人文主义无衬线 |
| 中文标题 | | **必须与拉丁衬线同气质** |
| 中文正文 | | 与英文正文字重对齐 |
| 等宽标签 | | 只在英文版用（多数无中文字形） |
| 兜底栈 | | 字体没加载完也不塌 |

**不用 `Inter` 做正文**，也不用 Roboto / Montserrat / Poppins / Open Sans（模板站最强信号）。

**落地要求**：字体**自托管** WOFF2 + `font-display: swap`，不引 CDN；中文字形做子集化。
换字体会牵动全部对齐数值（首屏巨字、侧栏对齐都按当前字体量的）→ **动手前先问用户**。

### 字号阶梯

| 层级 | 尺寸 | 字重 / 行高 | 用途 |
| --- | --- | --- | --- |
| Display | 用 `clamp()` | 衬线 / ≈0.95 | Hero 定位语、翻滚词墙 |
| H1 | 用 `clamp()` | 衬线 | 章节标题 |
| H2 | 用 `clamp()` | 衬线 | 小节标题 |
| H3 | 20–22px | 无衬线 600 / 1.35 | 卡片标题、图注 |
| Body-L | 18–19px / 1.7 | 无衬线 400 | Hero 副文案、TL;DR |
| Body | 16–17px / 1.75 | 无衬线 400 | 正文 |
| 中文正文 | 16–17px / **1.85** | 中文无衬线 400 | 中文行高比英文松 |
| Label | 12px / 1.6，大写 + 字距 | 等宽 400 | 状态标记、版本号 |
| Small | 14px / 1.6 | 无衬线 400，次要色 | 假设、脚注 |

**排版纪律**：一屏最多 3 种字号（首屏只允许 2 种）；英文标题衬线 → 中文标题**也必须是衬线**；
正文行宽 60–75 字符（中文 34–40 字）；不用全大写小字号英文段落、不拉开中文字距、不居中排超过 3 行的长段落。

## 5. 版式与网格

- 栅格：12 列、最大宽度 **1200px**、列间距 24px、页边 32px（移动 20px）。
- 纵向节奏：节内 24 / 40；节间距 96（移动）/ 160（桌面）。
- 圆角**小**（2px 级别）、边框 1px、**默认无投影**（浮层最多 8% 墨色）。
- 章节导航 = **右侧竖排巨字词轴**，当前章高亮，兼当锚点导航；
  **禁止**「左侧竖线 + 小圆点」的 `border-left` 引用块式章节轨。
- **每节布局必须不同**：可用手法池见 `layouts.md`。
- 可读性基线：正文对比度 ≥ 4.5:1；正文 ≥ 16px；点击目标 ≥ 44×44；`focus-visible` 必须可见。

## 6. 动效

- 只有三类：**翻滚词墙过场**（章节入口）、**滚动淡入**（`opacity` + 12px `translateY`）、**悬停细反馈**。
- 时长 200–400ms，缓动 `cubic-bezier(.22, 1, .36, 1)`；滚动关联动效只改 `transform` / `opacity`。
- 词墙**一屏一个词**，过场高度不超过 1 屏。
- 每章开头必须有「**10 秒读完**」TL;DR；任何动效**不得挡住 60 秒路径**（Hero → 作品 → 案例 → Demo）。
- `prefers-reduced-motion: reduce` 下全部动效退化为静态（词墙变静态词列表 + 锚点）。

## 7. 语气与文案

- 中文先行，英文从定稿中文**派生**（不逐字翻译），写 Product / Business English。
- 句式：先结论、后理由、再证据；一句话不超过 25 个中文字符 / 14 个英文单词。
- 工程词直接用（`workflow` / `checkpoint` / `human-in-the-loop` / `evaluation`）；
  **不用**「赋能 / 颠覆 / 重塑 / 一键」。
- 敢写负面：`这不是 X`、`agent 不做 Y`、`失败模式是 Z`。
- 三层口径分清：真实业绩（须与简历 / 背调口径一致）／模拟案例（标 `SIMULATED` / `MODELED`）／虚构 demo 数据（一眼可辨，如 `Client A` / `Northwind`）。

## 8. 禁忌清单（P0，逐条自检）

1. 不用 `Inter` 做正文，也不用 Roboto / Montserrat / Poppins / Open Sans。
2. 章节轨不用「竖线 + 小圆点」→ 用翻滚词轴。
3. `--ink-f` 不做正文；`--accent` 不做文字色。
4. Logo 颜色统一到品牌强调色，不要各页各色。
5. 每节布局必须不同；相邻两节同栅格、「三张等宽卡片」出现两次以上 = 不合格。
6. 不用大圆角 + 柔和投影的 SaaS 卡片风；不用霓虹渐变、紫蓝「AI 味」、3D 玻璃球、机器人插画。
7. 不用前端框架、不用打包工具、不引外部 CDN（字体自托管）。
8. 不放客户真名、银行信息、真实单据；demo 数据必须一眼看出是虚构。
9. 不在站里写求职申报类字样（`Applying to ...`）。
10. 不做 RESUME 页，不把「下载 PDF」当主 CTA。
11. 动效不得拖慢 60 秒路径；每章必须有 10 秒 TL;DR；reduced-motion 下全静态。
12. 中文版不做中英混排堆叠（中英各自独立页面）；等宽字体只出现在英文版。
13. 不把自我介绍写成形容词串 —— 每个形容词后面跟一个数字或一份产物。

## 9. 交付口径（每页改完的固定动作）

- 本地起静态服务 → 无头浏览器 / Playwright 截图（1440 与 390 两个宽度）留证据 → 更新进度记录。
- 每页过一遍：§8 十三条 + 对比度 + 60 秒路径有没有被挡住。
- 产物一律落项目目录（`site/`、`_preview/`、`tmp_out/`），**不动项目外原件**。
