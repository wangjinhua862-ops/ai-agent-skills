# 交付自检（checklist）

> 骨架来自 **ESTHER不二 / esther-design-system**（CC BY-NC-SA 4.0）的 P0/P1/P2，条目已换成本站口径。
> 改完每页逐条过；**P0 全过才交付**。

## P0（必须全过，任何一条不过就打回改）

- [ ] 暖纸底 `#F7F4EF` / 纸面 `#EFECE5`；不是纯白、不是暗色
- [ ] 标题用衬线、正文用无衬线；**没有** Inter / Roboto / Montserrat / Poppins / Open Sans
- [ ] 中文标题也是衬线，没有「英文衬线 + 中文黑体」混排
- [ ] 一屏最多 3 种字号（首屏 2 种）；字号走 `clamp()`
- [ ] 用色配比约 90:7:3；`--gold` 不做文字色且一屏最多一次；`--ink-f` 不承载阅读信息
- [ ] 每节布局不同；相邻两节不同栅格；「三张等宽卡片」全站不超过一次
- [ ] 没有默认 HTML 样式（默认 `blockquote` / `border-left` 引用块 / 无样式 `ul,ol` / 默认 `table`）
- [ ] 章节轨不是「左侧竖线 + 小圆点」
- [ ] 没有框架、没有打包工具、没有新增外部 CDN 依赖
- [ ] 正文对比度 ≥ 4.5:1；正文 ≥ 16px
- [ ] 点击目标 ≥ 44×44；`focus-visible` 有可见描边
- [ ] 改动**只落在用户指到的范围**，没有顺手加东西
- [ ] 有 1440×900 截图证据；对齐 / 位置类需求**量过像素**
- [ ] 60 秒路径没被挡住（Hero → 作品 → 案例 → Demo）
- [ ] 页面缩到 30% 看不清字时，仍像一份认真做的产品文档

## P1（应过）

- [ ] 滚动淡入 + stagger；时长 200–400ms，缓动 `cubic-bezier(.22,1,.36,1)`
- [ ] 悬停只有细反馈（下划线展开 / 边框加深），不做「变色 + 位移 + 发光」三连
- [ ] 每节开头有「10 秒读完」的 TL;DR
- [ ] `::selection` 用强调色
- [ ] 有一处大透明英文或大装饰数字做背景
- [ ] 字号对比足够极端（大的 > 48px，小的 ≤ 14px）

## P2（加分）

- [ ] 图片出血、溢出容器边界
- [ ] 全宽深色面板（整站最多一块）
- [ ] 条纹肌理 / 1px 细线分隔带 / 虚线段落用得克制
- [ ] `prefers-reduced-motion: reduce` 下全静态（词墙变静态列表 + 锚点）

## 交付前最后三问

1. 用户这句需求里的每个词都实现了吗？有没有多做？
2. 证据（数字 / 截图）能不能一行说清？
3. 预览图和改动说明发给用户时，他 F5 就能看到同样的结果吗？
