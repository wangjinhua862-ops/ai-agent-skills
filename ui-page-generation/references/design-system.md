# 设计规范（v3.1 定稿 · 取自 02-01 Agent 配置页实测值）

风格定位：Apple 的克制 + Linear 的精致 + AI Agent 的动态感 + 企业产品的可靠性。
配色比例目标：**90% 中性色 + 8% 品牌色 + 2% 状态色**。

> 本文所有数值都是 `src/pages/agent-config-v3.js` 里**正在跑的值**，不是理想值。
> 新页面一律照抄；要改先改代码、再回来改这里，两份不能不一致。

## 一、外壳（Shell）—— v3.1 定稿，最容易被做错的部分

1440×900 画布上，外壳由三块组成，**绘制顺序不能错**：

```
┌──────────────────────────────────────────────┐  ← 顶栏 1440×72，通栏白
│ Logo  ●工作区 ⌄   页面名        铃  头像      │
├────┬─────────────────────────────────────────┤
│导航│ 配置菜单（圆角浮空卡）   │  内容区 #F5F7F9 │
│ 56 │  224 宽，x=88           │   列宽 960     │
│ 通 │  y=88 → 画布底 900      │   x=344        │
│ 栏 │                         │   y=88         │
│ 到 │                         │                │
│ 底 │                         │                │
└────┴─────────────────────────┴────────────────┘
```

| 元素 | 尺寸与位置 | 样式 |
|---|---|---|
| 顶栏 | 1440×72，x=0 y=0 | 纯白 `#FFFFFF`，无描边无阴影 |
| **全局导航条** | **56×900，x=0 y=0（通栏到底）** | 纯白、**圆角 0**、无描边、**无阴影**，与顶栏连成一体 |
| **配置菜单 / 侧栏** | **224×792，x=88 y=88 → 底边 880** | **圆角 16 的浮空白卡**（v3Card），独立分区 |
| 统一间距与底边（2026-09-18 用户要求） | 间距**一律 20px**（导航条→侧栏、侧栏→内容、卡与卡之间、内容内左右分栏之间）；**所有卡底边收在 y=880**（底部留 20，别贴到 900） | 02-01 例外：形态保持不变（用户明确） |
| 内容区底色 | 其余区域 | `#F5F7F9` |
| 内容列 | 宽 960，**x=344** y=88 | 两侧间距**必须相等**：导航条→侧栏 32，侧栏→内容列 32（用户核对过） |

**绘制顺序**：先 `place(root, rail)` → 再 `place(root, topbar)` → 菜单 → 内容卡。
导航条和顶栏都是白色，先画导航条、后画顶栏，Logo 才不会被通栏的导航条盖住。

用户明确纠正过的两点（别再改回去）：

1. 导航条**不要**做成浮空圆角卡片、**不要**和顶栏/菜单之间留缝 —— 要通栏到底的直列。
2. 配置菜单**要**保持圆角浮空卡片（独立分区），**只**把高度拉到画布最下端；不要贴边、不要拉平成通栏列。

### 固定不变的三块（2026-09-18 用户明确要求：每页照抄，只有「页面名」和「主区内容」随页面变）

新页面**必须**直接复用这三块的代码与数值，不要重新设计、不要微调间距或字号：

**① 最左侧导航条**（`v3FillRail(rail, RAIL_TOP, H, activeKey, initials)`）

- 帧：56×900，x=0 y=0，纯白、圆角 0，通栏到画布底
- 图标固定 3 个，**分两处**（用户 2026-09-18 要求）：顶部两个 = 工作台（网格）→ 连接（两节点+连线）；**设置固定在最下面**（y = H−100，即缩写 chip 上方 16px）

- 每页只变 `activeKey`（02-02 = 工作台，02-01 = 连接）
- ⚠ **设置图标画成「滑杆」（三条横线 + 三个旋钮），不要画成「圆 + 8 条放射线」** —— 那会被看成太阳/主题切换（用户纠正过一次）；太阳属于顶栏

**② 顶栏**（`Top Bar`）

- 帧：1440×72，x=0 y=0，纯白
- 左：字母 Logo（近黑 `#0B0B0C`、26px）在 (16,22)
- 中左：6px 品牌色圆点（x=80，垂直居中）+ 工作区名 13/20/500 `#18181B`（x=94）+ 8px 后接 10px 展开箭头；页面名 15/22/600 `#18181B` 接在箭头右侧 34px 处

- **不显示用户姓名**；**通知铃不加数字角标**；只用这五个右端元素，不要再加图标
- 每页只变：工作区名（随语言）与页面名

**③ 问候卡**（主区第一张卡，`问候`）

- 卡片：v3Card，960×104，位置 (344, 88) —— 与 02-01 / 02-02 完全一致

- 副标题 14/22/400 `#71717A` 在 (24,60) —— 这是整张卡**唯一**可按页面替换的一句，不换也没问题

- **不要**在这张卡里加按钮、状态胶囊、头像或图表

> 结论：新页面的差异只应出现在「顶栏页面名 + 主区卡片」。导航条、顶栏右端、问候卡三块逐像素照抄。

### 品牌色

参考设计的静蓝 `#89B3DD` 只作状态色（太浅，不适合小字与交互）。本项目取其**加深兄弟色** `#4A7BB0` 作品牌色，浅底 `#EAF1F8`；需要更亮时用 `#6E9BC9`，但不铺大面积。

**注意 `src/tokens.js` 里是上一代 token（靛蓝 + 翠绿），页面已不使用；新页面照本文取值。**

## 四、字体

字体链（`makeText` 逐个尝试，取本机第一个装了的）：

- 中文：`PingFang SC → HarmonyOS Sans → Microsoft YaHei UI → Microsoft YaHei → Noto Sans SC → Source Han Sans SC → Source Han Sans CN → Hiragino Sans GB`
- 拉丁：`Inter → Helvetica Neue → Arial`（中文文本里的 `[A-Za-z0-9]` 段会自动切成拉丁字体）
- 等宽（数字/代号）：`SF Mono → JetBrains Mono → Consolas → Menlo → Monaco`
- **本机（Windows）实际落到**：中文 `Microsoft YaHei`、拉丁 `Inter` —— 在 Figma 里点「字体自检」按钮可复核

行高统一取 **字号的 1.4–1.5 倍**。
