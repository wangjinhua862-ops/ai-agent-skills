# 需求下单模板（用户 → 原型页）

用户给新页面的需求时，按下面的格式理解。**用户没说的项一律按默认值走，不要反问**。

## 一、最小可用写法（用户最常说的一种）

> 照 02-01 的风格，画 **02-02 权限设置**：左侧菜单选中「权限设置」，主区一张权限矩阵（OA / ERP / CRM × 可读 / 可写 / 需人工确认）。中文 + 英文。

一句话里有这四样就够开工：**页面编号 + 页面名 + 结构 + 要不要中英双版**。

## 二、标准模板（用户想说得细一点时）

```
【页面】02-02 权限设置        （中文 + 英文）
【目的】一句话说清这个页面替用户解决什么
【结构】可以画 ASCII，例如：
        ┌─ 顶栏（同上）────────────────────┐
        │ 配置菜单  │  标题 + 说明          │
        │ 选中：权限 │  权限矩阵卡           │
        └───────────┴──────────────────────┘
【文案/数据】真实字段、真实系统名、真实人名（没有的话我按现有 OA/ERP/CRM 三行推导）
【交互】静态帧即可 / 需要 hover 态（默认静态帧）
【风格】默认照 02-01 重构版，用户不写就不用管
```

## 三、更高保真的写法

- 给参考截图：放到桌面并说出文件名（例："参考桌面上的 微信图片_xxx.png"），我按图的图标/间距/配色还原。
- 给 ASCII 线框 + 每个区域的字号层级要求。
- 直接指着已有帧说："第 3 张卡片的高度和 02-01 的系统连接卡一样"。

## 四、改现有页面怎么说

> 改 02-01：配置菜单的高度拉到最底，保持圆角。

要点：**说清"哪一版、哪个元素、改成什么"**。像「导航栏不要分区、不要圆角」这种，我会先按参考图判断，如果两种理解都合理，我会先做一版再说明我的取舍。

## 五、默认值（用户不说时按这些走）

| 项目 | 默认 |
|---|---|
| 风格 | 02-01 重构版那套（见 `design-system.md`） |
| 画布 | 1440×900 |
| 语言 | 中文为主；用户说"中文+英文"或"英文版"时才出英文版 |
| 编号 | `模块-序号`，如 02-01、02-02、03-01；帧名 `02-02 重构｜权限设置` / `02-02 EN｜Permissions` |
| 版本 | 只出最新一版；旧版不留（用户 2026-09-18 明确要求删旧版） |
| 静态/交互 | 静态帧；hover、动效不画，除非用户点名要 |

## 六、我不会自己加的东西（用户没提就别加）

- 编造的业务指标、技术名词（响应时间、SLA、权限等级、OAuth、沙箱等）
- 用户没给的系统、字段、人名
- 额外的英文、额外的按钮、额外的页脚水印
- 新的配色（一律从 `design-system.md` 里取）

## 七、做完的标准交付话术

1. 改了哪个文件（`src/pages/*.js`）→ 构建 → 同步安装目录；
2. 告诉用户：**关掉插件面板 → 重新打开 → 点 ① 中文版 / ② 英文版**；
3. 附验收点（对齐、字阶、颜色、图标规格）；
4. 说明未验证项（真实观感需用户在 Figma 里看）。
